Why this works

Each correction is a KL projection.

A row update is the closest distribution to the current P, in KL divergence, among all distributions with the right row totals. A column update does the same for columns.

D(P* ∥ Pold) = D(P* ∥ Pnew) + D(Pnew ∥ Pold)

The last term is nonnegative. So the KL distance from the solution to the current table cannot increase at a projection. Individual row or column errors can rise again when the opposite margin is fitted.

Why it converges—and which solution it chooses

With a strictly positive seed and strictly positive normalized targets, a positive feasible table exists (for example, rᵢcⱼ). The alternating KL-projection theorem guarantees convergence to the unique minimizer of D(Q ∥ P⁽⁰⁾) over both marginal constraints. The identity above explains progress; monotonicity alone is not the full convergence proof.

Every iterate has the form Pᵢⱼ = uᵢPᵢⱼ⁽⁰⁾vⱼ. Row and column multipliers cancel in every 2 × 2 odds ratio. Thus IPF preserves the seed’s association structure; it does not generally produce the independent table rᵢcⱼ. Try the uniform preset to see that special case.

Natural logarithms give D(A ∥ B) = Σᵢⱼ Aᵢⱼ log(Aᵢⱼ / Bᵢⱼ) in nats. The order matters: the minimized objective is D(Q ∥ P⁽⁰⁾), while the decreasing diagnostic is D(P* ∥ P).

Numerical reference & stopping rule

The live run stops after a complete cycle when every absolute marginal error is at most ε. A safety limit of 2,000 cycles stops a slow run without claiming convergence. Zero entries are excluded in this demo: IPF preserves zeros, and feasibility then depends on the pattern of allowed cells. Displayed values are rounded; calculations use full precision.
