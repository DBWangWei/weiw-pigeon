Pigeon title effects are independent SVG adaptations of React Bits designs:
https://reactbits.dev/c/text-animations
https://github.com/DavidHDev/react-bits/tree/main/src/content/TextAnimations

Referenced designs: SplitText (staggered entrance), BlurText (blur/fade/move),
ShinyText (moving shine), GradientText (moving colors), TextType (sequential reveal).
The upstream React/GSAP/Motion components are not bundled. Pigeon uses original
Typst glyph outlines and the Web Animations API. Text Type reveals glyphs once;
Split/Blur operate on glyphs; color effects use a silhouette of the title.

Slide-transition patterns were reviewed from React Bits components including
FadeContent, AnimatedContent, Carousel, PixelTransition, Stack and
StaggeredMenu:
https://github.com/DavidHDev/react-bits/tree/main/src/content
Pigeon implements small dependency-free adaptations with the Web Animations API
and SVG clipping; the upstream React components are not bundled.
