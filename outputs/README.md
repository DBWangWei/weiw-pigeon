This folder contains the updated 20-slide Week 5 presentation and an installer
for the original Dropbox copy.

Open `pigeon-week5-introduction/index.html` to use the updated copy immediately.
Keep the whole presentation folder together for offline use.

To update the original presentation, double-click `Apply Week 5 Update.command`
in Finder, then reload its `index.html`. The updater checks the deck identity
and revision, backs up the five changed runtime files inside the destination,
and applies the update. Running it again makes no changes. Slides, source PDF,
embedded assets, deck identity and deck revision are preserved.

The original Dropbox folder is outside this Codex session's write permissions;
the attempted installation was blocked before any original file changed.

Display labels use SVG text. All drawing tools stay active for repeated
placement; press V to select and move objects. Horizontal and Vertical controls
set Left/Center/Right and Top/Middle/Bottom alignment. Free text defaults to
Left/Top, shape labels to Center/Middle, strokes to blue and fills to yellow.

Validation covers DOM interactions, real SVG/PNG text pixels, all alignment
combinations, sessions, undo, PDF export, and a smoke check of this exact deck.
Live browser appearance has not been visually verified in this session.
